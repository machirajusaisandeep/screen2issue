# Roadmap

## v1.0 release gates

- Trust foundation: light/dark/system theme, reduced motion, keyboard access, derived-artifact autosave and recovery.
- Core workflow: sample project, cancellable processing, evidence-first review, capability-aware enhancements, validated exports.
- Open source: typed compile-time adapters, schema guidance, diagnostics, design guidance, and CI coverage.
- Validation: five moderated developer sessions, offline PWA verification, quota/corruption/failure exercises, and manual screen-reader review.

Accounts, cloud storage, collaboration, telemetry, and arbitrary runtime plugins are intentionally out of scope.
